# 原脸五官与整体风格协调

`source-face-harmonized` 用于“脸要像本人，同时回贴区域要融入整张作品”。它是局部原脸合成，不是再次生成五官，也不承诺原像素不变。

## 处理原则

1. 先完成包含人物的整体拼贴，并以眼角和鼻尖做等比例旋转、缩放与移动。不得拉伸五官。
2. 从对齐后的原脸保留高频细节，包括眼睑、眉毛、鼻翼、嘴唇边缘和皮肤局部纹理。
3. 分别估计原脸与目标脸区域的低频成分，将两者的低频差乘以有限强度后加回原脸。当前算法等价于：`结果 = 原脸 + strength × (目标低频 - 原脸低频)`。
4. 默认 `harmonizeStrength=0.32`，允许 0 到 0.6。先用默认值；脸仍像贴片时小幅增加，身份感下降或肤色过度漂移时降低。不得为“更融合”超过上限。
5. 低频半径默认取原脸宽度约 3.5%，限制为 2–200 个源图像素。半径过小会碰到五官细节，过大则只能修正非常宽泛的色偏。
6. 外围继续使用 adaptive-ring 融合到发际线、耳侧和下颌等自然边界。低频协调不能替代轮廓检查。

## 视觉检查

- 和原图并排确认眼形、眼距、鼻形、嘴角、脸型、表情和人物对应关系。
- 查看肤色是否与脖子、头发、环境光相容，面部是否仍像独立贴纸。
- 100% 放大查看额头、太阳穴、耳侧、下颌以及相邻两张脸之间的接缝。
- 查看衣服和周围纸片是否持续相连；局部脸部协调不能成为回贴整个人物的理由。

验证报告对 harmonized 使用 `pixelsPassed: null` 与 `pixelVerification: not-applicable`。这不是失败，而是因为低频像素被有意修改。最终通过依赖文件来源校验和明确的视觉检查。若用户需要核心区零差异，应重新创建 `source-face-exact` 任务，不能沿用 harmonized 成品作严格声明。
